# 配置大厅交互草图

这是独立原型，仅使用示例数据演示，不连接账号写接口，不是配置大厅的实际实现。

在仓库根目录运行：

```powershell
node docs/config-hall/prototype/serve.mjs
```

然后打开 [本地预览](http://127.0.0.1:4173/)。顶部“查看场景”可以切换大厅、首次分享、已经分享、空结果、加载失败和登录提示。

可以体验职业过滤、按使用人数/点赞排序、分享码查找、点赞/取消、查看详情、选择目标角色复制，以及取消/勾选分享后的保存语义。复制分享链接使用本地预览地址，仅在预览服务运行时有效。

刷新会恢复初始示例数据。编辑页仅演示基础/战斗/补给三个分区和新增的分享区域，正式实现将接入现有完整编辑器。

六套示例配置、作者名称、人数和点赞均定义于 `data.js`；职业图标复用本仓库 `apps/web/public/ui/pticons/`。没有外部图片或字体下载。

设计依据和验证见 [交互记录](../ux-notes.md)。预览图片保存在同级 `../preview/`。
