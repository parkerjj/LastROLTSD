# 登记簿设计

## 目标

为 LastROWeb 增加公开登记簿，让访客无需登录即可发布收购、出售或网站建议，并浏览、筛选、检索其他访客发布的内容。新功能沿用网站现有的暖纸色、低饱和森林绿、红色强调色、品牌页眉和简洁边框风格。

## 已确认的产品规则

- 三类登记内容：收购、出售、网站建议。所有内容提交后立即公开，不需要登录或人工审核。
- 收购和出售必须包含目录中的道具 ItemID 或特殊的 Zeny 项、联系方式及详细内容，并选择 1、3、7 天或永久时效。
- Zeny 是独立的商品类型，不分配或伪造 ItemID。
- 网站建议只需要正文，可以完全匿名，不要求道具、联系方式或有效期。
- 到期记录继续保留在数据库、浏览列表和检索结果中。界面降低其对比度，并在内容之外显示显著的“已过期”印章。
- 留言暂不提供编辑、删除、回复、举报或管理审核入口。

## 架构

新增一张 MySQL 登记簿表和一组 Worker API 路由。正式 Worker 请求目前由 `apps/worker/src/index.ts` 创建 MySQL repository；本功能只扩展此生产存储路径，不为保留的 D1 repository 增加第二套 API/存储实现。

表记录类别、可空 `item_id`、商品类型（普通道具或 Zeny）、可空联系方式、正文、创建时间和可空到期时间。建议类别不带道具或联系方式，过期时间为空；交易类别的永久选项过期时间为空。表上为类别/创建时间、ItemID/创建时间及到期时间建立合适索引。到期状态在读取时由 `expires_at <= now` 推导，不依靠定时删除或定时状态更新。

建议路由：

- `GET /api/v1/guestbook`：支持类别、ItemID、关键词、游标及有限页大小；返回新到旧记录、是否过期和下一页游标。过期记录不做过滤。
- `POST /api/v1/guestbook`：匿名提交；Worker 重新校验类别字段组合、目录中的有效 ItemID、正文/联系方式长度、时效选项和 JSON 请求大小。

列表采用 `created_at` 与递增主键组成的稳定排序键和 HMAC 签名游标，避免大 OFFSET。分类、道具和时间筛选通过索引约束；关键词对登记内容及联系方式做转义后的字面子串匹配，不把用户输入拼成 SQL。查询页大小有固定上限。API 不返回访客 IP，也不存储明文 IP。

匿名写入具有垃圾信息风险。提交路由基于 Cloudflare 提供的客户端 IP 生成带服务器密钥的摘要，并用 MySQL 短时间桶实现原子频率限制；客户端不能通过自带转发头绕过限流。超限返回 429，数据库或限流检查失败时写入失败关闭。限流状态有索引和过期清理路径，避免无界增长。

## Web UI

新增 `/guestbook` 页面模块并在现有主导航和页脚加入入口。页面提供类别筛选、道具自动补全、关键词检索、游标翻页、发布类别切换及相应表单。

- 收购/出售表单：交易方向、道具自动补全或 Zeny、联系方式、详细内容、1/3/7 天或永久期限。
- 建议表单：仅有内容输入；不要求或暗中收集联系方式。
- 留言记录显示类别、道具/Zeny、联系方式（仅交易类）、内容和创建/到期信息。
- 过期记录通过整条记录降对比度及独立印章标注；不能仅靠颜色表达状态，不能遮挡或截断正文。
- 提供加载、空列表、请求失败、表单校验、提交成功/失败和限流反馈；支持键盘操作、屏幕阅读器标签及窄屏布局。
- 页面复用项目现有 Phosphor 图标、目录数据和 CSS 设计令牌，不引入新的 UI 框架或图标族。

## 安全与验证

正文和联系方式均以纯文本处理并在 DOM 输出时转义；数据库查询全用参数绑定。请求体大小、查询长度、正文长度和联系方式长度均有 Worker 端硬限制。ItemID 必须由服务器校验为已知目录项；浏览器自动补全不是安全边界。

测试覆盖 MySQL 迁移、发布字段矩阵、无效字段和目录 ID 拒绝、HTML 内容安全、过期记录仍可检索且正确标记、分类/ItemID/关键词筛选、游标稳定性、匿名限流与失败关闭、路由错误响应及页面交互。运行相关 Worker/Web 测试、类型检查、完整测试套件和生产构建，并在桌面和手机视口检查页面。

## 不在本次范围

- 登录身份、留言所有权、编辑/删除、回复、举报、审核队列、附件和管理员管理页面。
- D1/SQLite 的第二套登记簿存储实现。
- 自动删除过期留言或隐藏过期留言。
- IP 明文持久化或向其他访客暴露提交者网络信息。
