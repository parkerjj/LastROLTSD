LRO 进阶客户端 / ISOLATED WEB APP

进阶客户端

基于 Chrome IWA（Isolated Web App）技术打造的下一代 LastRO 客户端。以网页形态分发安装，以接近原生应用的体验运行——无限帧率、离线挂机、装备免鉴定，一切从这套全新的开源架构开始。

仅限电脑端 Chrome 浏览器 预计兼容 Edge 完全开源
当前版本
v0.1.0测试版

签名 Release（Chrome IWA）。当前为测试版框架，也是后续一切「黑科技」的基础。安装无需手动下载——Chrome 会自动拉取最新安装包。

签名 Release 版Chrome IWA（.swbn）
环境要求

本客户端仅支持电脑端：请使用桌面版 Google Chrome 浏览器安装（Microsoft Edge 预计可用，未完整验证）。暂不支持手机与平板。

INSTALL GUIDE

三步完成安装

按步骤操作即可，全程无需下载文件、无需命令行。Chrome 会通过更新地址自动拉取最新安装包。

01

开启 IWA 开发者模式

在地址栏依次打开 和 ，都设为 Enabled，然后点击 Relaunch 重启 Chrome。这两个开关只需开启一次。

02

在 chrome://web-app-internals 中安装

地址栏打开 ，找到 Install IWA from Update Manifest，粘贴更新地址 后点击安装。Chrome 会自动拉取最新安装包，无需手动下载。若其他教程提到的 chrome://iwa-dev 显示 ERR_INVALID_URL，请使用此入口。

03

确认并启动

在安装向导中确认应用名称与版本后点击安装。完成后从开始菜单或应用列表打开「LRO 进阶客户端」，像原生程序一样独立窗口运行。

为什么需要开发者模式？Chrome 目前仅允许进入官方应用列表的 IWA 免开关直接安装；未入列的签名 Release 包（如本客户端）必须开启 Developer Mode 后才能安装。该开关为浏览器级设置，开启一次即可，不影响浏览器其他功能。

进阶客户端不是旧客户端的补丁，而是一套重写的新架构。以下为主要差异一览。

KNOWN ISSUES

已知问题

当前为测试版框架，以下问题已确认存在，将在后续版本中修复。

  1. 1

    NPC 对话选择空条目会掉线

    与 NPC 对话时，如果选中了空条目再点击确定，会导致与服务器断开连接。请避免点击空白选项。

    待修复
  2. 2

    活动公告未实现快速传送

    服务器公告发送的活动信息目前以原文形式显示，暂未实现「点我快速传送」功能。

    待实现
  3. 3

    NPC 商店输入数字时容易失焦

    与 NPC 交易购买输入数量时，输入框容易失去焦点，需要重新点击输入框。

    待修复
  4. 4

    铁匠精炼界面闪烁

    铁匠精炼时 UI 会出现闪烁现象，但不影响精炼功能的正常使用。

    不影响使用
